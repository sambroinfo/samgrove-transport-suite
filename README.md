# SAMGROVE Transport Suite

I am developing SAMGROVE Office Transport v1.0.0 entirely from an Android phone.

Build the responsive web application foundation for a professional multi-tenant office transportation management SaaS.

Brand: SAMGROVE Office Transport. Tagline: Move Smarter. Arrive Together. Version 1.0.0.

Requirements: Modern premium enterprise dashboard; responsive mobile, tablet and desktop layout; mobile-friendly sidebar; header with profile, notifications and language selector; login and password reset screens; dashboard summary cards and vehicle map placeholder; navigation for Dashboard, Employees, Drivers, Vehicles, Routes, Trips, GPS Tracking, Notifications, Chat, Emergencies, Reports and Settings. Use React and TypeScript. Prepare for my existing Supabase project. Inspect the connected database before using tables or columns. Do not invent database fields, expose secret keys or present placeholder information as live data. First build only the design system, authentication screens, responsive navigation and dashboard. @connector:github:"GitHub API"
